## How to study
1. Read one numbered file at a time.
2. Perform its matching exercise in an authorized Windows test environment.
3. Save sanitized screenshots, event exports and command output.
4. Mark a lab Verified only after reviewing actual evidence.

**Portfolio status:** Theory and lab instructions are published. Installation, event generation, forwarding, detections and investigations remain unverified until performed by the learner.

**Safety:** Use systems you own or are authorized to administer. Do not publish credentials, tokens, private keys or unredacted logs.
