# Example Defensive Scripts

These are small educational examples using the Python standard library. Review code before running. Use only files and systems you own or are authorized to assess. They do not scan networks, execute log content or contact external services.

From the repository root:
~~~bash
python python-cybersecurity/scripts/file_integrity.py --help
python python-cybersecurity/scripts/log_summary.py --help
python python-cybersecurity/scripts/ioc_matcher.py --help
python python-cybersecurity/scripts/system_inventory.py
~~~

Review and sanitize all output before publication.
