# 16 — Linux Glossary and Learning Resources

## Glossary
- APT: Debian-family package manager interface.
- Bash: a common command-line shell.
- CLI: command-line interface.
- Daemon: background service process.
- Distro: complete operating system built around the Linux kernel and supporting software.
- Filesystem: method and structures used to organize files.
- Kernel: core component managing hardware and system resources.
- Mount point: directory where a filesystem is attached.
- Package: software bundle managed by a package manager.
- PID: process identifier.
- Root: top directory /, or the superuser account depending on context.
- SSH: encrypted protocol for remote shell and administration.
- Sudo: tool for running approved commands with elevated privileges.
- systemd: common Linux init and service manager.
- TTY: terminal device/session concept.
- VM: virtual machine.

## Official documentation
Use official documentation as the primary reference because commands and defaults can change:
- Linux kernel documentation: https://docs.kernel.org/
- Ubuntu documentation: https://documentation.ubuntu.com/
- Debian documentation: https://www.debian.org/doc/
- Kali Linux documentation: https://www.kali.org/docs/
- VirtualBox manual: https://www.virtualbox.org/manual/
- GNU Bash manual: https://www.gnu.org/software/bash/manual/
- systemd documentation: https://www.freedesktop.org/software/systemd/man/
- Nmap reference guide: https://nmap.org/book/man.html
- Wireshark documentation: https://www.wireshark.org/docs/

## Suggested study method
1. Read one concept.
2. Explain it in your own words without copying.
3. Run the command in a disposable VM.
4. Predict the output before running it.
5. Compare expected and actual results.
6. Record one mistake and how you fixed it.
7. Add a sanitized screenshot or script to your portfolio.

## Interview preparation questions
1. Difference between Linux and Kali Linux?
2. What does the kernel do?
3. Explain /etc, /var/log, /home and /root.
4. Explain chmod 750.
5. Difference between a process and a service?
6. How do you check listening ports?
7. How would you investigate repeated failed SSH logins?
8. Difference between apt update and apt upgrade?
9. Difference between NAT and Host-only VM networking?
10. Why must security testing be authorized?
