# 15 — Linux & Kali Skills Checklist for Cybersecurity Students

## Linux concepts
- [ ] Explain kernel, shell, terminal, user space and distribution.
- [ ] Describe boot process and systemd.
- [ ] Explain filesystem hierarchy.
- [ ] Distinguish absolute and relative paths.
- [ ] Explain files, directories, links and mount points.

## Administration
- [ ] Navigate and manage files from terminal.
- [ ] Read and search text files.
- [ ] Create users and groups.
- [ ] Explain ownership and rwx permissions.
- [ ] Use sudo and least privilege.
- [ ] Inspect processes and services.
- [ ] Install, update and remove packages safely.
- [ ] Inspect storage and resource usage.
- [ ] Configure basic networking and firewall rules.
- [ ] Read system and authentication logs.

## Automation
- [ ] Write a Bash script with variables.
- [ ] Use if/else and loops.
- [ ] Write functions and check exit codes.
- [ ] Create a safe system inventory script.
- [ ] Avoid hard-coded secrets and unsafe command construction.

## Security operations
- [ ] Identify listening ports and running services.
- [ ] Review failed login events.
- [ ] Explain SSH security basics.
- [ ] Apply a basic hardening checklist.
- [ ] Explain evidence preservation and time correlation.

## Kali and tools
- [ ] Explain Kali's purpose and limitations.
- [ ] Install Kali in a VM and configure an isolated lab network.
- [ ] Explain NAT, bridged, host-only and internal network modes.
- [ ] Use Nmap only within authorized scope.
- [ ] Capture own lab traffic with Wireshark/tcpdump.
- [ ] Explain Burp Suite, ZAP and Metasploit roles.
- [ ] Produce a clear technical report.

## Portfolio proof
- [ ] Add sanitized screenshots.
- [ ] Include scripts with comments and usage instructions.
- [ ] Add a network diagram and IP plan.
- [ ] Document troubleshooting and remediation.
- [ ] Clearly distinguish planned work from completed work.
- [ ] Remove credentials, tokens, private keys and personal data before every commit.
