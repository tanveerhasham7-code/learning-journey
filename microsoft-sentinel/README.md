## Study method
1. Read the numbered files in order.
2. Use a Microsoft Learn sandbox, eligible trial or subscription only after reviewing current eligibility, pricing and regional availability.
3. Prefer synthetic/sample data for initial KQL practice.
4. Never connect personal or employer logs without authorization.
5. Save sanitized query results, screenshots and configuration evidence.
6. Mark a task Verified only after you perform it and inspect the actual result.

**Portfolio status:** Theory and lab blueprint are published. Azure deployment, ingestion, detections, automation and incident investigations remain unverified until completed with real evidence.

**Cost and safety:** Sentinel and its underlying Log Analytics ingestion, retention and automation services can incur charges. Review current pricing, free grants, trial terms, budgets and cleanup steps before enabling paid resources.
