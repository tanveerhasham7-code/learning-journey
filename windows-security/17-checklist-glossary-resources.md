# 17 — Skills Checklist, Glossary and Resources

## Skills checklist
Mark an item complete only when you can explain and demonstrate it.

### Windows administration
- [ ] Explain user mode and kernel mode.
- [ ] Identify Windows edition, version and build.
- [ ] Inspect local users, groups and administrator membership.
- [ ] Explain authentication and authorization.
- [ ] Configure and verify NTFS permissions on a test folder.
- [ ] Inspect processes, services and scheduled tasks.
- [ ] Use PowerShell pipeline, filtering and simple scripts.

### Defensive security
- [ ] Inspect network configuration and connections.
- [ ] Review Event Viewer and build a basic timeline.
- [ ] Verify firewall profile status and rules.
- [ ] Review Microsoft Defender status.
- [ ] Explain UAC, Secure Boot and BitLocker.
- [ ] Review Group Policy and resultant policy.
- [ ] Explain AD DS, domains, OUs, groups, DNS and Kerberos.
- [ ] Complete a Windows hardening assessment.
- [ ] Write a lab report with sanitized evidence.

## Glossary
- **AD DS:** Active Directory Domain Services.
- **Authentication:** proving an identity.
- **Authorization:** deciding what an identity may access.
- **DC:** domain controller.
- **GPO:** Group Policy Object.
- **Kerberos:** ticket-based network authentication.
- **LDAP:** directory access protocol.
- **NTFS:** Windows file system with access-control features.
- **OU:** Organizational Unit in Active Directory.
- **PowerShell:** object-based shell and scripting language.
- **SID:** Security Identifier.
- **UAC:** User Account Control.
- **Least privilege:** minimum access required for a task.
- **Endpoint:** a device connected to a network.
