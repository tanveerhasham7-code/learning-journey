# Cybersecurity Fundamentals — Beginner to Advanced

This is the fourth stage of my learning journey, after Networking, Linux, and Windows, and before Python for Cybersecurity. It connects operating-system and networking knowledge to security concepts used by analysts and security engineers.

## How to study
1. Read modules in order and write notes in your own words.
2. Learn definitions, compare related concepts, and use examples.
3. Complete practical tasks only on your own device or an isolated, authorized lab.
4. Record actual observations and sanitized screenshots.
5. Never claim a practical is complete until you have performed it.

## Completion standard
Explain core concepts in your own words, identify a basic risk, recommend proportionate controls, and describe a safe incident-response process. Practical completion requires your own recorded evidence.

## Safety
Only assess systems you own or have explicit permission to test. No public/third-party scanning, password spraying, denial-of-service, malware execution, credential theft, or destructive testing.
