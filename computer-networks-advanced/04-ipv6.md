# 04 — IPv6 Networking and Security

## 1. Why IPv6?
IPv6 provides a 128-bit address space and was designed to address IPv4 exhaustion and improve aspects of IP operation. IPv6 is not simply IPv4 with longer addresses; it has different address types, neighbor discovery and autoconfiguration behavior.

Example: `2001:db8:10::25/64`. The `2001:db8::/32` block is reserved for documentation examples and should not be used as a real public allocation.

## 2. Address types
- **Global unicast:** globally routable address space.
- **Unique local:** private-like internal addressing, commonly in fc00::/7 (locally assigned addresses generally use fd00::/8).
- **Link-local:** fe80::/10; used on a local link for neighbor discovery and other functions.
- **Multicast:** one-to-many delivery; IPv6 does not use broadcast.
- **Loopback:** ::1.
- **Unspecified:** ::, used in limited protocol contexts.

## 3. Prefixes and subnetting
IPv6 networks are written using prefix length, such as /64. A /64 is common for end-user LANs because SLAAC and many IPv6 functions expect it. Organizations plan larger allocations hierarchically and assign /64s to LAN segments.

## 4. Neighbor Discovery Protocol (NDP)
NDP uses ICMPv6 messages for functions including router discovery, address resolution, reachability detection and redirect behavior. It replaces several IPv4 mechanisms such as ARP and router discovery.

Security concerns include rogue router advertisements and neighbor spoofing. Defenses may include RA Guard, DHCPv6 Guard, SEND where supported, switch protections and monitoring. Correct implementation depends on device support and topology.

## 5. SLAAC and DHCPv6
- **SLAAC:** hosts use router advertisements to learn prefixes and configure addresses.
- **Stateful DHCPv6:** a DHCPv6 server assigns addresses and related options.
- **Stateless DHCPv6:** hosts form addresses through SLAAC but may obtain other configuration from DHCPv6.

Do not assume DHCPv6 behaves exactly like IPv4 DHCP.

## 6. Dual stack and transition risks
Many environments run IPv4 and IPv6 together. If defenders secure only IPv4, IPv6 may provide an overlooked path. Inventory both protocol stacks, apply equivalent policy, monitor both and disable neither casually without understanding dependencies.

## 7. Useful checks
Linux:
```bash
ip -6 address
ip -6 route
ip -6 neigh
ping -6 <authorized-lab-address>
```
Windows PowerShell:
```powershell
Get-NetIPAddress -AddressFamily IPv6
Get-NetRoute -AddressFamily IPv6
Get-NetNeighbor -AddressFamily IPv6
```

## Practical lab
Create two IPv6 LANs in a simulator or isolated VM network. Assign /64 prefixes, configure router interfaces, verify neighbor discovery and routing, and capture ICMPv6 router solicitation/advertisement traffic in Wireshark. Document the difference between link-local and global addresses.

## Security checklist
- Are IPv6 firewall rules enabled and reviewed?
- Are router advertisements limited to trusted network devices?
- Is IPv6 management traffic restricted?
- Are DNS records and monitoring prepared for IPv6?
- Are IPv4 and IPv6 access policies equivalent?
