# 15 — Networking Checklist for a Cybersecurity Student

## Foundations
- [ ] Explain LAN, WAN, WLAN, PAN and common topologies.
- [ ] Explain switch, router, firewall, access point and NIC.
- [ ] Explain bandwidth, throughput, latency, jitter and packet loss.
- [ ] Explain encapsulation and OSI/TCP-IP models.
- [ ] Distinguish MAC, IP and port addressing.

## Addressing and infrastructure
- [ ] Convert IPv4 addresses between binary and decimal.
- [ ] Calculate network, broadcast, host range and prefix.
- [ ] Explain private/public IPv4 and basic IPv6.
- [ ] Configure static IP and DHCP clients.
- [ ] Explain ARP, DNS, DHCP, NAT and NTP.
- [ ] Configure access VLANs and trunks in a simulator.
- [ ] Explain inter-VLAN routing and static routes.

## Operations
- [ ] Use Windows and Linux network commands.
- [ ] Read a routing table and ARP/neighbor table.
- [ ] Identify common TCP/UDP ports.
- [ ] Troubleshoot using a layered approach.
- [ ] Draw and explain a network topology.

## Security
- [ ] Explain segmentation and least privilege.
- [ ] Explain firewall, IDS, IPS, VPN and NAC.
- [ ] Explain ARP spoofing, DNS abuse, DoS/DDoS and MITM at a conceptual level.
- [ ] Explain secure Wi-Fi configuration.
- [ ] Identify unnecessary exposed services.
- [ ] Understand logs, timestamps and traffic baselining.
- [ ] Use Wireshark on authorized lab traffic.
- [ ] Use Nmap only within authorized scope.

## Portfolio evidence
- [ ] Save Packet Tracer/GNS3 topology files.
- [ ] Add readable diagrams and IP tables.
- [ ] Include sanitized screenshots and command output.
- [ ] Write what worked, what failed and how it was fixed.
- [ ] Never upload passwords, tokens, private keys, personal data or unredacted sensitive captures.
- [ ] Clearly label planned, in-progress and completed labs.
