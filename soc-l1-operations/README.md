# SOC Level 1 Operations — Theory and Practical Learning Path

This module fills operational knowledge areas that a Junior SOC Analyst (Tier 1) is expected to understand beyond SIEM queries and tool familiarity. It is a learning guide, not a claim of professional SOC employment or completed practical work.

## Learning path

1. [Email and phishing alert investigation](01-email-and-phishing-investigation.md)
2. [SOC ticketing, case management and escalation](02-ticketing-case-management-and-escalation.md)
3. [Vulnerability management for SOC analysts](03-vulnerability-management-for-soc.md)
4. [Identity threat monitoring and account compromise](04-identity-threat-monitoring.md)
5. [SOC operations, metrics and shift handover](05-soc-operations-metrics-and-handover.md)

## How to study

For each topic, learn the workflow and terminology first. Then perform the exercises only in an authorized lab or with synthetic data. Record the alert/source, time range, evidence, analysis, decision, escalation, and limitations. Never publish real user data, email contents, credentials, tokens, or unredacted logs.

## Junior SOC Analyst L1 completion standard

You should be able to acknowledge an alert, validate its context, gather relevant evidence, distinguish true positive / false positive / benign positive / inconclusive outcomes, assign an appropriate severity and priority, document a reproducible case, escalate when required, and hand over unresolved work clearly.

## Important boundaries

A Tier 1 analyst follows approved playbooks and access permissions. Do not independently disable accounts, isolate endpoints, delete emails, block infrastructure, or make production changes unless the organization's policy and authorization explicitly allow it.
