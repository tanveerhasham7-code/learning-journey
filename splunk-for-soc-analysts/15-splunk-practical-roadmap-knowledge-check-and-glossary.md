## Glossary
- **Alert:** notification generated by defined search conditions.
- **CIM:** Common Information Model for normalized security and IT data.
- **Correlation search:** analytic that evaluates activity and may create a finding.
- **Event:** one searchable record.
- **Field:** named value extracted from an event.
- **Forwarder:** component that sends data to Splunk.
- **Index:** logical store for indexed events.
- **Indexer:** role that processes and stores incoming events.
- **Notable event:** security finding in Splunk ES workflows.
- **RBA:** risk-based alerting that accumulates risk observations around entities.
- **Search Head:** analyst interface and search-processing role.
- **SPL:** Search Processing Language.
- **Sourcetype:** classification describing event format.
- **TA:** technology add-on providing product-specific knowledge and configuration.
- **Threat hunting:** proactive hypothesis-led search for suspicious behavior.
- **Universal Forwarder:** lightweight Splunk collection and forwarding agent.

## Evidence checklist
For every lab save objective/date, topology and versions, exact query, time range and timezone, sanitized screenshot or output, interpretation, limitations, troubleshooting, and next improvement.

## Portfolio integrity
Mark practical tasks complete only after personally running them and saving genuine evidence. Never publish passwords, tokens, private keys, customer data, or unredacted logs.
